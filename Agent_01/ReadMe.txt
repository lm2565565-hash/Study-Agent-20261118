特点：自主做决策
路径规划能力：自主调用工具、mcp服务、skill

Agent前置条件：
大模型（负责思考和决策）
工具集合（提供可执行的能力）
用户任务（告诉智能体要完成什么）
执行机制（负责调用工具并把结果反馈给模型）

agent是大模型根据任务和执行结果决定下一步做什么

为什么能调用工具？核心 Function Calling
大模型只是能够按照约定的格式，生成工具调用的请求

#工具
def query_stock(sku:str):
  return {"sku":sku,"stock":20}
pass

让大模型知道这个工具【工具说明书】
用户：查询 sku001 的库存
大模型不会直接回答，会生成一个结构化的工具调用请求
{
  "name":"query_stock",
  "arguments":{
  "sku":sku001
  }
}
接下来由agent运行框架负责真正执行python函数

llm               判断调用哪个工具 生成参数
agent runtime     接收工具请求、查找并执行工具
tool              执行实际业务逻辑并返回结果

技能、mcp 都是相同的道理
